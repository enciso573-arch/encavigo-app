Tarifa: $25 si así lo acordaron; los espacios gratuitos de publicidad no eliminan la comisión automáticamente. Fechas: las acordadas con el negocio.

Formato Ideal: Vertical (9:16) estilo TikTok/Reels.
Medidas Recomendadas: 1080 x 1920 píxeles (Mínimo 720 x 1280).
Peso: Menor a 500KB (Formato JPG o WEBP) para que no gaste los datos del pasajero.
Nota: Si subes una foto cuadrada u horizontal, el sistema la recortará automáticamente (Zoom) para llenar la pantalla vertical.
