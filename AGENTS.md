# EncaviGO: criterios para cambios en este repositorio

Consultar `ESPECIFICACION-MAESTRA.md` y `OPERACION-LISTA.md` para distinguir funciones implementadas de propuestas futuras.

El procedimiento de `PROCESO-PROMOCIONES.md` es obligatorio para promociones con canje. Mantener la ficha privada, cálculo con datos proporcionados por el negocio, beneficio real, contribución mínima, comisión y cupos autorizados. No permitir publicar sin evaluación correspondiente y acuerdo confirmado. Conservar este control en el panel y en las reglas de Firebase. Copiar una oferta no transfiere la aprobación.

Conservar la apariencia existente salvo que el propietario solicite un cambio de diseño. Los ejemplos deben identificarse como hipotéticos y nunca crear datos en producción.

Verificar los cambios de cálculo, aprobación o reglas con las pruebas relacionadas y el recorrido aislado. Las pruebas de Firebase se ejecutan exclusivamente en `demo-encavigo-audit` con emuladores locales. No activar facturación ni inventar negocios, choferes, pagos o premios para ensayar en el proyecto real.
